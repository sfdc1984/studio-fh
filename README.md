# FH Residency — GitHub-ready project

This is the cleaned FH Residency static site package.

## Start here
Open `index.html` locally, or deploy the folder as a static site.

## Real vs AI
- `images/real-*` = original property/building photographs supplied for this project.
- `images/ai-*` = AI visualisations only.
- The site labels the AI section explicitly and does not use AI images in the REAL gallery.

## Deployment
The project is static. Put `index.html`, `theme.css`, `app.js`, and `images/` at the root of the GitHub repository. Vercel can serve it as a static site with no build command.
